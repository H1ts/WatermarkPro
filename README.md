# WatermarkPro

Веб-платформа для кинопродакшена. Позволяет загрузить видеофайл, автоматически наложить персонализированный водяной знак (ФИО клиента + таймкод), добавить логотип, и выдать защищённую ссылку для просмотра через HLS-стриминг. Встроенная система рецензирования с таймкодовыми комментариями и аннотациями на видео.

**Целевая аудитория:** операторы, постпродакшен, продакшен-компании, рентал-хаусы в РФ.

## Возможности

### Загрузка и обработка
- **Drag & drop загрузка** — перетаскивание или выбор видеофайла любого формата
- **Проекты** — группировка файлов по проектам (Dashboard → Project → Upload)
- **Текстовый watermark** — ФИО клиента с настраиваемой позицией (drag на превью), прозрачностью (20–80%) и размером шрифта (16–120px)
- **Лого watermark** — наложение PNG/JPG/WebP логотипа поверх видео (до 5 МБ, масштаб 10–50%)
- **Burn-in таймкод** — вшитый таймкод вверху кадра, 36px, автоопределение FPS (24/25/30/48/50/60)
- **3 пресета качества** — низкое (ultrafast/CRF 28), среднее (medium/CRF 23), лучшее (slow/CRF 18)
- **Форматы вывода** — MP4 и MOV (ProRes-совместимый контейнер)
- **Прогресс обработки** — отслеживание в реальном времени (0–100%)

### Просмотр и доставка
- **HLS-стриминг** — сегментированное воспроизведение в браузере без возможности скачать
- **Защита от скачивания** — блокировка правого клика, HLS-only доставка
- **Скачивание** — кнопка скачивания готового файла (MP4/MOV)
- **Уникальная ссылка** — отдельный URL для каждого обработанного видео

### Рецензирование (Review & Comments)
- **Таймкодовые комментарии** — комментарии привязаны к конкретному моменту видео
- **Аннотации на видео** — рисование поверх кадра (карандаш, стрелка, круг, прямоугольник)
- **Палитра цветов** — 5 цветов для аннотаций
- **Маркеры на таймлайне** — визуальные метки комментариев на полосе воспроизведения
- **Resolve/Delete** — пометка комментариев как решённых, удаление
- **Клавиатурные сокращения** — Space (play/pause), Escape (отмена аннотации)

## Быстрый старт

```bash
git clone https://github.com/H1ts/WatermarkPro.git
cd WatermarkPro
docker compose up --build -d
```

Откройте http://localhost в браузере.

## Деплой на VPS

```bash
# На сервере (Ubuntu/Debian), от root:
DOMAIN=your-server-ip bash deploy.sh
```

Или вручную:

```bash
echo "BASE_URL=http://your-server-ip" > .env
docker compose up --build -d
```

## Архитектура

```
Browser (React SPA)
  → Nginx (reverse proxy, port 80)
    → /             → Frontend (React SPA)
    → /api/*        → FastAPI (projects, upload, process, status, comments)
    → /watch/*      → FastAPI (встроенный HLS-плеер)
    → /review/*     → Frontend (страница рецензирования)
    → /hls/*        → Статические HLS-сегменты
      ↓
    FastAPI → FFmpeg (watermark + timecode + logo → MP4/MOV → HLS)
           → Redis (проекты, задачи, комментарии)
```

## Сервисы

| Сервис | Порт | Описание |
|--------|------|----------|
| nginx | 80 | Реверс-прокси, SPA routing, раздача HLS-сегментов |
| api | 8000 | FastAPI бэкенд, обработка видео, API комментариев |
| frontend | — | React SPA (раздаётся через nginx) |
| redis | 6379 | Хранение проектов, задач, комментариев |

## Пайплайн обработки (FFmpeg)

1. **Определение FPS** — автоматическое через ffprobe (24/25/30/48/50/60)
2. **Нормализация PTS** — сброс стартового таймкода камеры в 00:00:00:00
3. **Водяной знак** — текст ФИО, настраиваемая позиция/размер/прозрачность
4. **Логотип** — overlay с масштабированием и прозрачностью (если загружен)
5. **Таймкод** — вверху по центру, 36px, привязка к FPS исходника
6. **Кодирование** — H.264 (libx264) + AAC 128k → MP4/MOV, 3 пресета качества
7. **HLS-сегментация** — codec copy, сегменты по 6 сек → .m3u8 + .ts

```
├── frontend/               # React SPA
│   ├── src/
│   │   ├── App.js          # Роутер (Dashboard, Project, Review)
│   │   ├── Dashboard.js    # Список проектов, создание

├── CLAUDE.md               # Контекст проекта для AI-ассистента
└── .env                    # BASE_URL (создаётся при деплое)
```
